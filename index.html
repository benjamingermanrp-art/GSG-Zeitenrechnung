Globale Discord-Namen (GitHub)

Eingetragene Discord-Namen werden in discord-mapping.json im GitHub-Repo gespeichert und sind für alle sichtbar, die die Seite öffnen. Zum Speichern braucht dieser Browser einen GitHub-Token mit Schreibrecht. Ohne Token werden die Namen nur geladen, eigene Änderungen bleiben lokal.

Kein Token hinterlegt
So erstellst du den Token
  1. Auf GitHub: Profilbild → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Bei Repository access „Only select repositories“ wählen und nur GSG-Zeitenrechnung auswählen.
  3. Bei Permissions → Contents und Actions jeweils auf „Read and write“ stellen (Actions braucht der Button „Aus Discord holen“).
  4. Token erzeugen, kopieren und oben einfügen.

Der Token wird nur in diesem Browser gespeichert. Niemals in den Code, ins Repo oder in Discord posten – wer ihn hat, kann das Repo ändern.

Discord-Bot einrichten (Usernames automatisch holen)

Beim Kopieren aus Discord kommen nur Nicknames mit. Ein eigener Bot liest deshalb die Mitgliederliste und ordnet jedem Nickname mit Dienstnummer (z. B. [GUF-68] Sarah Salzberg) den Discord-Username zu. Einmalig einrichten:

  1. Auf discord.com/developers/applications → New Application (Name z. B. „GSG Abgleich“).
  2. Links Bot → Reset Token → Token kopieren. Weiter unten Server Members Intent einschalten und speichern.
  3. Links OAuth2 → URL Generator → Scope bot anhaken (keine Rechte nötig) → Link öffnen → euren Server auswählen.
  4. In Discord: Einstellungen → Erweitert → Entwicklermodus an. Dann Rechtsklick auf euren Server → Server-ID kopieren.
  5. Auf GitHub im Repo: Settings → Secrets and variables → Actions → New repository secret: DISCORD_BOT_TOKEN (Bot-Token) und DISCORD_GUILD_ID (Server-ID).
  6. Fertig: Der Abgleich läuft alle 6 Stunden von selbst. Sofort geht es über Aus Discord holen oder auf GitHub unter Actions → „Discord-Mitglieder aktualisieren“ → Run workflow.

Den Bot-Token nur als GitHub-Secret speichern – nie hier eintragen, ins Repo schreiben oder in Discord posten.
